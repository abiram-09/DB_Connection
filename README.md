# # DB Connection – Core Java Web Application

A Java-based web application built using **Core Java, Jakarta Servlets, Apache Tomcat, and MySQL**.  
The project demonstrates how a Java web application connects to a MySQL database and implements basic student registration and login functionality.

## Features

- Student registration
- Student login
- MySQL database connectivity using JDBC
- Servlet-based request handling
- HTML/CSS-based user interface
- Apache Tomcat deployment
- Database operations using SQL

## Technologies Used

- **Java 17**
- **Jakarta Servlets**
- **JDBC**
- **MySQL**
- **Apache Tomcat 10.1**
- **HTML5**
- **CSS3**
- **Eclipse IDE**
- **Git & GitHub**
